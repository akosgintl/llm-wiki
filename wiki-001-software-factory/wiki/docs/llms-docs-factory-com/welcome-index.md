# Welcome to Factory

> [[raw/docs/llms-docs-factory-com/welcome-index|Raw]] · llms-txt · https://docs.factory.com/welcome/index.md

## Summary

This is the entry page of the Factory docs (docs.factory.com). It positions Factory's agent, Droid, as one thing that "runs the same everywhere", and frames adoption as a ramp: delegate a first coding task, then automate the wider SDLC, then roll out across an enterprise. [[raw/docs/llms-docs-factory-com/welcome-index#Choose a path|cite]]

Three surfaces are offered: the Factory App (desktop, Mac and Windows incl. ARM), the Droid CLI (one-line install via curl, Homebrew, PowerShell or npm), and Web & Mobile, which needs no install and relies on cloud session sync and "Droid Computers" to reach sessions from a browser. [[raw/docs/llms-docs-factory-com/welcome-index#Start with a surface|cite]]

The page is mostly a router. Its doc map names the sections: product surfaces, a Software Factory section (triage, code review, QA, docs, incident response), platform capabilities (Missions, model independence, autonomy controls, harness customization), enterprise (deployment, security, identity, telemetry), an API reference (sessions, computers, wikis, analytics) and a changelog. [[raw/docs/llms-docs-factory-com/welcome-index#Explore the docs|cite]]

## Key claims

- Factory's pitch scales "from a single session to an automated SDLC". [[raw/docs/llms-docs-factory-com/welcome-index#Welcome to Factory|cite]]
- Three entry paths: ship code faster, automate the full SDLC (code review, QA, documentation across repos), plan an enterprise rollout. [[raw/docs/llms-docs-factory-com/welcome-index#Choose a path|cite]]
- Droid is available as desktop app, CLI (`droid`) and browser/mobile via cloud sessions and Droid Computers. [[raw/docs/llms-docs-factory-com/welcome-index#Start with a surface|cite]]
- Factory names a "Software Factory" product area covering triage, code review, QA, docs and incident response. [[raw/docs/llms-docs-factory-com/welcome-index#Explore the docs|cite]]
- The API can drive sessions, computers, wikis and analytics programmatically. [[raw/docs/llms-docs-factory-com/welcome-index#Explore the docs|cite]]
