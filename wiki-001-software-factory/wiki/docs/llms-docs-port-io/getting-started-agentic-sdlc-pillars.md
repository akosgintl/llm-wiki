# The pillars of an AI software factory

> [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars|Raw]] · llms-txt · [docs.port.io](https://docs.port.io/getting-started/agentic-sdlc-pillars.md)

## Summary

Port presents itself as "the platform for building your organization's AI software factory", the system that runs an agentic SDLC safely across teams. The page is a short orientation. It splits the factory floor into six pillars and maps each to a step of Port's Port-AI-driven onboarding. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#The pillars of an AI software factory|cite]]

The model is layered. A context lake holds unified engineering knowledge. Workflows act on it. Port AI guides the work. Agent management governs the agents that do it. An interface builder keeps teams informed. Governance enforces access and standards. The context lake is the base: "AI agents reason over it, workflows act on it, and dashboards visualize it." [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Context lake|cite]]

This is a vendor framing of the software factory idea, built around a catalog and data layer rather than around coding-agent runners.

## Key claims

- The context lake connects repositories, cloud resources, incidents and deployments into one semantically rich source of truth that powers everything else in Port. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Context lake|cite]]
- Workflows are visual, node-based automations with chained operations and conditional logic. Users trigger them manually, or catalog events trigger them. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Workflows & tools|cite]]
- Port AI is a conversational assistant that guides setup, helps build workflows and dashboards, and answers catalog questions. It drives the whole onboarding. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Port AI|cite]]
- Agent management is the layer for building and governing agents, including an AI registry for skills, prompts and MCP server access. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Agent management|cite]]
- The interface builder offers dashboards plus on-demand workflow triggers. Approval flows keep the right people involved. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Interface builder|cite]]
- Governance has two parts: access controls (RBAC, SSO, teams, audit trails) and standards enforcement through scorecards for security, reliability and production readiness. [[raw/docs/llms-docs-port-io/getting-started-agentic-sdlc-pillars#Governance|cite]]
